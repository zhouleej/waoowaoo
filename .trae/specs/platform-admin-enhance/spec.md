# 平台管理功能增强规格

## 为什么

当前平台管理页面功能过于基础，仅展示列表和简单的禁用/启用操作。管理员需要完整的管理能力：搜索、筛选、分页、查看详情、增删改等操作。

## 什么变化

- 组织管理页面：增加搜索、筛选、分页、查看详情（成员列表、余额信息）、管理员充值
- 用户管理页面：增加搜索、分页、查看详情（所属组织、消费记录）、锁定/解锁、设置/取消管理员
- 系统配置页面：增加新增配置、删除配置功能
- 所有页面增加分页组件

## 影响

- 受影响代码：
  - `src/app/[locale]/admin/platform/organizations/page.tsx` - 组织管理页面增强
  - `src/app/[locale]/admin/platform/users/page.tsx` - 用户管理页面增强
  - `src/app/[locale]/admin/platform/config/page.tsx` - 系统配置页面增强
  - `src/app/api/platform/` - 相关 API 增强
  - `messages/zh/platform.json` - 新增翻译键
  - `messages/en/platform.json` - 新增翻译键

## 新增需求

### 需求：组织管理增强

系统 SHALL 提供完整的组织管理功能。

#### 场景：搜索组织
- **WHEN** 管理员在搜索框输入关键词
- **THEN** 系统按名称或 slug 模糊搜索并展示结果

#### 场景：筛选组织
- **WHEN** 管理员选择状态筛选（全部/正常/已禁用）
- **THEN** 系统按状态过滤组织列表

#### 场景：查看组织详情
- **WHEN** 管理员点击某组织行
- **THEN** 系统展示组织详情弹窗（成员列表、余额、消费统计）

#### 场景：组织充值
- **WHEN** 管理员为某组织充值
- **THEN** 系统增加组织余额并记录操作日志

### 需求：用户管理增强

系统 SHALL 提供完整的用户管理功能。

#### 场景：搜索用户
- **WHEN** 管理员在搜索框输入用户名或邮箱
- **THEN** 系统模糊搜索并展示结果

#### 场景：查看用户详情
- **WHEN** 管理员点击某用户行
- **THEN** 系统展示用户详情弹窗（所属组织、消费记录）

#### 场景：锁定/解锁用户
- **WHEN** 管理员锁定某用户
- **THEN** 该用户无法登录系统

#### 场景：设置/取消管理员
- **WHEN** 管理员将某用户设置为管理员或取消管理员
- **THEN** 系统更新用户权限

### 需求：系统配置增强

系统 SHALL 提供完整的配置管理功能。

#### 场景：新增配置
- **WHEN** 管理员点击新增配置按钮并填写配置信息
- **THEN** 系统创建新配置项

#### 场景：删除配置
- **WHEN** 管理员删除某配置项
- **THEN** 系统移除该配置

## 技术设计要点

### 前端组件

- 搜索栏组件（输入框 + 搜索按钮）
- 筛选器组件（状态下拉）
- 分页组件（上一页/下一页 + 页码）
- 详情弹窗组件

### API 增强

- `PATCH /api/platform/users/[id]` - 更新用户（锁定/解锁、设置管理员）
- `POST /api/platform/config` - 新增配置
- `DELETE /api/platform/config/[id]` - 删除配置
- `POST /api/platform/organizations/[id]/balance` - 组织充值
